# Premium School Website

A modern, responsive school homepage built with React, Vite, Tailwind CSS, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Add your school information

Open `src/data/schoolData.js` and replace:

- `[SCHOOL NAME]`
- `[SCHOOL LOGO]`
- `[SCHOOL SLOGAN]`
- `[PHONE NUMBER]`
- `[EMAIL ADDRESS]`
- `[FULL SCHOOL ADDRESS]`
- `[PRINCIPAL NAME]`
- `[PRINCIPAL PHOTO]`
- `[WHATSAPP NUMBER]`
- `[GOOGLE MAPS EMBED LINK]`
- `[GOOGLE MAPS LOCATION LINK]`

The enquiry and newsletter forms currently show successful front-end states. Connect them to your backend, Formspree, EmailJS or another form service when deploying.
